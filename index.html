TRANSPARENCE

Comment lire les variations

Une hausse du prix day-ahead de demain reflète l’enchère pour demain. Les mesures RTE ci-dessous décrivent des heures déjà écoulées ; les comparer permet de formuler des hypothèses, pas de prouver la cause d’un prix futur.

Le gaz électrique, l'éolien, le solaire et le solde d'import/export seront affichés après la première collecte RTE.

Un solde RTE négatif signifie une exportation nette ; positif, une importation nette. Les données sont des télémesures complétées d'estimations.

Transparence ENTSO-E ↗

Références de marché

Prix day-ahead : enchère de la veille. Intraday continu : échanges ultérieurs du même créneau, avec indices ID1 / ID3. Prix d’équilibrage : règlement d’un mécanisme différent. Un spread exige des valeurs comparables et datées.

Définitions EPEX ↗ · Transparence ENTSO-E ↗

Méthode et qualité des mesures

Observé provisoire : RTE éCO2mix, dernier relevé de chaque heure UTC. Calculé : demande résiduelle = consommation − éolien − solaire ; ce calcul ne représente pas le dispatch réel d'une centrale ni un prix. Les trous de collecte restent visibles dans la courbe.

La couverture réelle, la date de mesure et l'heure de collecte sont affichées. Le fichier HTML embarque l'historique ; « Actualiser les données » le synchronise depuis GitHub si le réseau le permet.

Les jetons ENTSO-E et GIE restent dans les secrets GitHub.
